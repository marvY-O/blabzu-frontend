# blabzu

blabzu — India's place to decide, not just scroll. Real, save-worthy recommendations on beauty, fashion, food, gadgets, and travel from real people, in Hindi, Tamil, Telugu, Bengali, and more.

This is the prelaunch landing page for blabzu, launching soon on Android, iOS, and Web.

## Structure

- `index.html` — landing page markup
- `style.css` — styles
- `script.js` — page scripts
- `scripts/` — build/utility scripts
- `assets/` — images and branding assets
- `robots.txt` / `sitemap.xml` — SEO files

## Running locally

Serve the directory with any static file server, e.g.:

```
npx serve .
```

Then open the printed local URL in your browser.
